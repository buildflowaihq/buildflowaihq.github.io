# BuildFlowAI

Public pages for BuildFlowAI (served at https://buildflowaihq.github.io/).

- `/` : BuildFlowAI request page. Each person opens their own private link (`?k=...`), adds it to their home screen, and sends requests. Keys live in Apps Script, never in this repo.
- `/intake/` : new-client intake form.

Keep this separate from Mercy Street. Do not put keys, tokens or client data in this repo (it is public).
